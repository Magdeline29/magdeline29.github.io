# User Stories and Tasks — PowerShare

## Evidence available
The Trello export includes sprint-labelled cards with user stories and three checklist tasks per story. One example is the Sprint 1 Day 1 registration story:

> As a new customer, I want to create an account so that I can access the PowerShare battery rental services.

The associated tasks recorded on the board are:
- Design registration screen UI
- Implement registration form
- Validate required user information

All three checklist items were marked complete in the export. This documents board status; it is not independent verification of the implementation or testing.

The Sprint 2 Day 1 catalogue story covers viewing available batteries. Its tasks include designing the catalogue, displaying battery cards and adding battery images; the image task was still incomplete in the export.

## What this demonstrates
The examples show a user-centred story being broken down into smaller tasks. The stories span customer registration, login, battery discovery, booking, payment, rental management, profile and support.
